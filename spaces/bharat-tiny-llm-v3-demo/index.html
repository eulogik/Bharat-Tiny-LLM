Run it yourself

API: model="eulogik/Bharat-Tiny-LLM-v3:featherless-ai" via router.huggingface.co/v1 (OpenAI-compatible, see model page for snippets).

llama.cpp (math): llama-cli -m bharat-tiny-llm-v3-q4_k_m.gguf -p "नमस्ते"

llama.cpp (chat): llama-cli -m brahmi-v3.3-q4_k_m.gguf -p "नमस्ते" — v3.3 is the chat-tuned variant (GSM 35% on llama/Q4, pinned protocol).

Offline GGUFs: in the model repo (*-q4_k_m.gguf, *-f16.gguf).

FAQ

Is my data private? Chats are sent to the Featherless AI inference endpoint to generate replies — like any hosted demo. For fully offline use, download the GGUF and run it with llama.cpp.

Which languages? Hindi (Devanagari), Hinglish (Romanized Hindi+English), and English.

Why do I need a token? The inference provider requires authentication. A free read-only token takes 30 seconds at huggingface.co/settings/tokens.

What can it do well? Short Hindi math (e.g. 17×23=391), factual Q&A, and grade-school math word problems. Conversational quality is limited in v3 — see v3.3 GGUF for better chat.

Why is the output sometimes garbled? v3 was trained primarily on math + QA data, not conversations, and the base model leaks non-Hindi scripts. This page sends repetition penalty 1.25 and scrubs junk scripts, repeated sentences, and placeholder tokens — but long chats can still drift. Short questions work best.
